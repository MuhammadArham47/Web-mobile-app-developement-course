## 🧭 About This Repository
 
This repository is my personal logbook for the **Web & App Development** program at **SMIT (Saylani Mass IT Training)**. Every commit here represents a step forward — an assignment solved, a concept understood, a bug squashed.
 
Instead of scattering my work across folders on my laptop, I'm building this repo as a **single source of truth** for my learning journey — clean, organized, and version-controlled.
 
> 💡 *If you're a fellow SMIT student, a recruiter, or just curious — feel free to explore and follow along as this repo grows week by week.*
 
<br>
